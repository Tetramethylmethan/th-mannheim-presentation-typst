# TH Mannheim Presentation Typst
The unofficial TH Mannheim typst presentation Template.
This project is a work in progress.
It is based on "clearly hm" https://github.com/towoe/clearly-hm and uses Polylux as Slide Package.

This work has been done by Falko Piwinger, as part of his Position of Student Councile President. Please note that any use of the Logo not related to Technische Hochschule Mannheim may be prohibited.
